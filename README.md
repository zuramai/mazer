# Mazer - Task 3 Dashboard Customization

This repository is a fork of [Mazer Admin Dashboard](https://github.com/zuramai/mazer), customized as part of **Task 3 – Front-End Skill Assessment**. The project demonstrates front-end customization, dynamic data integration, and theme enhancements using Bootstrap 5, JavaScript, and Chart.js.

---

## 🔹 Features Implemented

### 1. Dynamic KPI Cards
- Active Users
- New Signups
- Revenue
- Open Tickets
- All KPIs are dynamically fetched from `assets/data/data.json`.

### 2. Weekly Activity Chart
- Visual representation of weekly activity using **Chart.js**.
- Data driven from `assets/data/data.json`.

### 3. Recent Activity Table
- Displays the latest actions performed by users.
- Includes columns: Time, User, Action, Status.
- Dynamically populated from JSON data.

### 4. Profile Section
- User profile card with avatar, name, and username.
- Recent messages list.

### 5. Theme Enhancements
- Added multiple themes (Light, Dark, Ocean).
- Background colors and styles enhanced for better UI/UX.

---

## 🔹 Technologies Used
- **Frontend:** HTML5, SCSS, JavaScript (ES6)
- **UI Framework:** Bootstrap 5
- **Charts:** Chart.js
- **Package Management:** npm
- **Data Storage:** Local JSON (`assets/data/data.json`)
